# 入力検証パック（使い捨て）

`doc/BedrockControlSpec.md` に残っている未確認事項のうち、実機がないと白黒つかない2点を検証するための最小ビヘイビアパック。

- **4-1 案D**：オフハンドに置いたカスタム武器を、ZL/ZR等の押下がメインハンドと区別して検知できるか
- **4-4**：L/Rボタン（ホットバーカーソル移動）を特殊技ボタンとして間接検知できるか

検証が終わったら消してよい使い捨てパックです。恒久的な実装には使いません。

## 導入方法

1. `bedrock-verification/` フォルダを、そのままVPS上のBDSの `behavior_packs/` 配下にコピーする
2. ワールドの `world_behavior_packs.json` にこのパックのUUID（`manifest.json`内）を追加して有効化
3. ワールド設定で「ベータAPI」「スクリプトAPI」等の実験的機能が必要な場合は有効にする（バージョンによる）
4. サーバーを起動し、Switch Pro Controllerで参加する

## 検証1：オフハンド武器の判定（4-1 案D）

1. `/give @s minetrigger_test:offhand_weapon` でテスト武器を入手
2. インベントリを開き、テスト武器を**本物のオフハンドスロット**（盾アイコンの位置）にセットする
3. メインハンド（ホットバー）には別の適当なアイテム（例：素手や別の武器）を持つ
4. 何もない方向・ブロック・敵、それぞれに向けてZL・ZRを押す
5. チャットに流れるログを確認する

### 見るべきポイント

- `itemUse`/`itemUseOn`/`itemStartUseOn`/`playerInteractWithEntity` が**テスト武器（オフハンドの中身）を伴って発火するか**
  - 発火しない・常にメインハンドの中身しか出てこない → オフハンド武器はボタンで能動的に発動できない（見た目だけ左手、というのが確定になる）
  - オフハンドの中身が伴って発火する → 独立して発動できる可能性がある。ログの `mainhand=` `offhand=` の中身を見比べて、どちらが実際に反応しているか確認する

## 検証2：L/Rボタンの間接検知（4-4）

1. 適当にホットバーにアイテムを複数入れておく
2. Lボタン・Rボタンを連打し、ログの「hotbar変化」が**押した回数と一致して漏れなく出るか**、**体感でラグが気になるか**を確認する

### 見るべきポイント

- 連打しても取りこぼしなく毎回イベントが出るか
- イベントが来てから「選択スロットを元に戻す」処理を挟んだ場合、画面上でホットバーの選択枠がチラつくかどうか（今回のパックには「元に戻す」処理は含めていないので、まずは素の挙動を見てから判断する）

## 結果の反映先

検証結果が出たら `doc/BedrockControlSpec.md` の該当箇所（4-1, 4-4）を確定情報に更新する。
